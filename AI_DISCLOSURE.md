# Use of AI tools

An AI coding assistant (Claude Code, Anthropic) was used as a tool for writing and debugging code, running jobs on the
investigators' computer, and checking text against the results files. The investigators set the study question, the
task families, the floors, the comparators, the metrics, the margins, every lock and the registration, and they decided
every deviation; these decisions are recorded in `results/EXECUTION_LOG.md`. The investigators checked the outputs the
assistant produced. The assistant is not an author and is not a contributor to this repository.
