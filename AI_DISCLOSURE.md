# Use of AI tools

An AI coding assistant (Opus 5.5, Claude Code, Anthropic) was used as a tool for writing and debugging code, running jobs on the
investigators' computer, and checking text against the results files. The investigators set the study question, the
task families, the floors, the comparators, the metrics, the margins, every lock and the registration, and they decided
every deviation (`results/DEVIATIONS.md`). The investigators checked and verified all code and outputs.
